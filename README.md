A-Top

A modern, lightweight terminal system monitor for DevOps and SRE engineers.

A-Top is a TUI-based Linux system monitoring tool designed as a modern alternative to traditional tools such as top, htop, and btop.

It provides a clean terminal interface for monitoring system health, with real-time metrics presented through compact widgets and charts.

The goal is simple:

Fast visibility into system health without leaving the terminal.

✨ Features
System Monitoring

A-Top is being built around modular monitoring widgets for:

🖥️ CPU utilization
🧠 Memory utilization
💾 Disk usage
🌐 Network activity
⚙️ Processes
🔧 Services

Each metric is designed as an independent widget so additional monitoring capabilities can be added without changing the core application.

Terminal UI

Grid-based dashboard

Line charts for historical values
